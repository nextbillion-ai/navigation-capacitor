# NextBillion Capacitor Navigation

This repository contains a distributable Capacitor plugin and an example app. The example uses the plugin as an npm dependency; the plugin owns the native bridge, SDK dependencies, and automatic registration.

```text
plugin/       Distributable npm plugin: TypeScript API, iOS Swift, Android Java, and native dependencies
example/      Complete Capacitor example: embedded native map, trip panel, grouped settings, and full-screen native navigation
artifacts/    Plugin .tgz archives generated by npm pack (local build output)
scripts/      Packaging and standalone consumer installation checks
docs/         Architecture guides and feature screenshots
```

## Quick start

Requirements: Node.js 20+, JDK 21 for Android, Android SDK 35 for Android, and Xcode for iOS. The project supports Capacitor 7, Android API 23+, and iOS 14+ with Swift Package Manager.

```sh
npm ci
npm run sync
npm run android
# or npm run ios
```

`npm run dev` starts a browser preview. Route calculation and navigation require the installed iOS or Android app. Open **Settings → Connection**, enter your NextBillion API key with Maps and Navigation access, and select **Apply settings** to connect the embedded native map. Choose a sample trip or edit the origin, destination, and intermediate stops, then generate routes. Navigation simulation is enabled by default.

The example supports Car, Truck, Bicycle, and Motorcycle routing profiles; nine road and maneuver avoidances; and truck dimensions (centimeters), loaded weight (kilograms), axle load (metric tonnes), hazardous cargo, truck type, and truck-road preference. Settings are grouped by vehicle, avoidances, and truck configuration, with Apply and Cancel actions. Applying changes that affect routing requires a new route calculation. Truck settings include presets, explicit units, and an option to clear optional restrictions and use service defaults.

## Plugin distribution

```sh
npm run pack:plugin
```

This creates `artifacts/nextbillion-navigation-capacitor-1.0.0.tgz`, which can be delivered directly to customers.

Customers install the archive from their Capacitor app directory:

```sh
npm install /path/to/nextbillion-navigation-capacitor-1.0.0.tgz
npx cap sync
```

See the [plugin guide](plugin/README.md) for integration examples, iOS permissions, and SPM requirements. The plugin supplies the Android Activity, manifest permissions, and SDK dependencies, which are merged automatically. iOS SDK dependencies are declared in the plugin's `Package.swift`.

The build produces a distributable archive without publishing it to the npm registry. The package name in this repository is `@nextbillion/navigation-capacitor`. Before publishing, use an npm scope you control and confirm the applicable license.

## Verification and maintenance

```sh
npm run verify:package
```

This packages the plugin, installs the actual `.tgz` in a temporary consumer project, compiles its TypeScript and web example, checks unsupported-platform errors in browsers, and runs Capacitor synchronization to verify automatic registration and native dependencies on both platforms. It does not rely on relative imports of the plugin source from the example.

See the [example guide](example/README.md) for native build and device test instructions. The [architecture guide](docs/plugin-architecture.md) describes the layering, method mapping, and distribution boundaries adapted from the Flutter project.

Native SDK versions are pinned to iOS Navigation **4.1.1** and Android Navigation **3.1.0**. SDK upgrades are managed in the plugin; the example does not declare NextBillion SDK versions directly.
